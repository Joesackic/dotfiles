# Dotfiles

My personal desktop configuration.

| Directory | Contains |
| --- | --- |
| `hypr/` | Hyprland and Hyprlock configuration |
| `waybar/` | Waybar configuration and styling |
| `awww/` | Wallpaper scripts |
| `kitty/` | Kitty terminal configuration |
| `starship/` | Starship prompt configuration |

The main Hyprland config is `hypr/.config/hypr/hyprland.lua`. It loads monitor settings generated by hyprmoncfg from `hyprmoncfg-monitors.lua`.

The wallpaper scripts use images from `~/Images/Wallpapers/`.
